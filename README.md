# Cordova RP

Site da cidade. A loja cobra no Mercado Pago e, depois da confirmação, avisa o Discord e entrega no jogo.

O arquivo `.env.example` diz como obter cada variável e onde ela entra. Localmente, copie para `.env.local`. Na Vercel, as mesmas chaves ficam em Settings → Environment Variables.

O webhook do Discord não vem configurado. A URL criada no canal entra em `DISCORD_WEBHOOK_URL`.
